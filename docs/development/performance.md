# Performance

Measure CPU rendering, hardware WGPU, software WGPU, media decode/encode, audio execution, and end-to-end rendering separately. Record the command, revision, scene, output settings, backend preference, actual backend, adapter name, device classification, and environment. Do not compare a software adapter run with hardware results.

llvmpipe and Lavapipe results must not be described as hardware-GPU benchmarks. Historical measurements live in [History](../history/README.md); they are evidence from their original environment, not current claims.
