# History

These files describe Vestra at the time they were written. They are historical
records, not normative documentation for the current engine. Use the current
Getting Started, Concepts, Guides, Reference, Troubleshooting, and Development
pages for current behavior.

`audits/` contains implementation reviews and completion records.
`migrations/` records completed API or architecture migrations.
`benchmarks/` preserves measurements and performance investigations. A result
there is evidence from its original environment, not a current performance
claim.
