## Reproduce the small assets

The font is from Google Fonts revision
`b31870aff700ab7a1d74fa0c6887d95beb9e0037`. Its SHA-256 is
`3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`.
The original photo's SHA-256 is
`6936f552123608df0552d3b3ddaaeabdff3ed233e669b04676ac8078d6c0aad6`.

Download the original photo from
[the pinned original file](https://upload.wikimedia.org/wikipedia/commons/e/e5/Landscape_in_Salzburger_Land.jpg)
and reproduce the checked-in derivative with FFmpeg:

```bash
ffmpeg -i landscape-original.jpg -vf scale=1600:-1 -map_metadata -1 -q:v 3 landscape.jpg
```

Encoding bytes can differ by FFmpeg version; the source checksum identifies the
input. The original 4.3 MiB photo is not committed; the small derivative is bundled.

## Stylized effects synthetic inputs

The [stylized effects scene](stylized-effects/README.md) generates its moving
video and periodic harmonic soundtrack locally with FFmpeg. The analytic image and
motion expressions are original project work distributed under MIT; no external
footage or audio is downloaded. Generated media remains under `target/`.
The [fine-detail/ASCII reference example](stylized-effects/reference.py) also
generates an original synthetic portrait, including hair/cloth texture and
periodic subject motion. It does not redistribute the AcerolaFX screenshot.
The blue-noise threshold tile is also original MIT-licensed project work,
reproducible with `scripts/generate-blue-noise.py`; it contains no downloaded
texture or third-party shader code.
The custom ASCII example uses `tests/assets/VestraTest-Regular.ttf` (DejaVu
Sans), with its complete Bitstream Vera/DejaVu notice in
[the adjacent license](../../tests/assets/VestraTest-Regular.ttf.license).
Preserve that notice when redistributing the font; rendered glyph images are
distinct from the font source file.

## Rendered outputs

Each of the six showcases includes a `render.mp4`, `poster.jpg` and compact animated
`preview.gif` (silent). These are actual CPU renders of the accompanying Python projects
at 1280×720 and 30 fps (the asset-free quickstart is 640×360). They may be viewed or downloaded directly on GitHub.
The README demo and media edit (including their previews/posters) contain the
CC0 footage above. Other outputs use the CC0 photograph/audio, OFL font, and
original project graphics. The software MIT license does not supersede those asset terms.

The [README quickstart](quickstart/README.md) contains only original geometric
graphics, with no font, audio or external media. Its source and rendered outputs
are MIT licensed. The README hero uses the CC0 Shanghai footage and synthesized
audio, plus the OFL font above. Its audio is used for analysis only; the exported MP4 is silent.

The [effects lookbook](lookbook/README.md) reuses the CC0 landscape and OFL
Manrope font. Its ASCII treatment uses Vestra’s bundled DejaVu face; the
[Bitstream Vera/DejaVu notice](../../tests/assets/VestraTest-Regular.ttf.license)
also accompanies that face. No new third-party inputs are introduced.
