# Tutorial programs

These Python files are the runnable sources used in the documentation. After
installing Vestra, run a file from any directory. Outputs go to the current
directory. Scripts using `overwrite=True` replace their outputs on rerun.

Start with the [first animation tutorial](../../docs/getting-started/first-animation.md)
or run [first_animation.py](first_animation.py). The effects catalog needs
`landscape-study.jpg` beside the script if downloaded separately. [Shared study image](../../assets/images/README.md)

Try [nightcore_remix.py](nightcore_remix.py) for a generated stereo remix
with linked speed, room reverb and a filtered delay throw.
[Run the remix](../../docs/guides/python/audio.md#remix-a-stereo-phrase)

Try [phrase_remix.py](phrase_remix.py) for a stereo lead-in, chorus and
turnaround using filter sweep, beat repeat, pitch shift and tape stop.
[Run the phrase remix](../../docs/guides/python/audio.md#edit-into-a-chorus)

Try [styled_subtitles.py](styled_subtitles.py) for SRT captions, word
highlighting, a typewriter title and a selectable MP4 track.
[Run the subtitle example](../../docs/guides/python/subtitles.md#run-the-subtitle-example)

To regenerate previews, see [documentation media](../../docs/development/documentation-media.md#reproduce-tutorial-previews).
