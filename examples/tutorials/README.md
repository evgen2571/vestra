# Tutorial programs

These are the runnable sources included directly by the documentation. Run them
from any directory after installing Vestra; outputs are written to the current
directory. Examples using `overwrite=True` replace their named outputs on rerun.

`effects_catalog.py` reads the shared [study crop](../../assets/images/README.md).
When downloading that program alone, put `landscape-study.jpg` beside it.
The other programs generate their own scenes and need no external inputs.

`first_animation.py` is kept identical to the [quickstart showcase](../showcase/quickstart/main.py)
by `just site-check`. Preview generation is described in
[documentation media](../../docs/development/documentation-media.md).
